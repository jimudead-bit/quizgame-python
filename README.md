# 🎮 Simple Python Quiz Game 

This is a simple, beginner-friendly Python quiz game you can run right in your terminal. It asks three multiple-choice questions and keeps track of your score as you go.

## 🚀 Features

* 📝 Three trivia questions: Fun everyday topics like ingredients, science, and animals
* 🔢 Multiple-choice format: Choose from a, b, or c for each question
* 📊 Score tracking: Your score updates are shown after each question
* 🔠 Case-insensitive answers: A and a both work

## 🛠️ Requirements

To run this game, you just need Python 3 installed on your computer

## 🏃 How to Run the Game

* 📂 Open Python IDLE (it comes installed with Python)
* 📄 Click File → Open and select the quiz_game.py file
*     Press F5 (or click Run → Run Module) to start the game 🎮


## 🕹️ Example Gameplay

```text

Good Luck!

What is the necessary ingredient in finger fries?
a) Potatoes
b) Tomatoes
c) Onions

Correct!
```
